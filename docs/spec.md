- 復刻對象：**ギョ～転！ガッポリすし ～あっぱれ!!～**（ENHEART，2019/10 稼動，8 人小型版，16 格）
- 撰寫：2026-08-20
- 狀態：**待使用者確認**（確認後才進實作）

## 0. 原則與來源標籤

- 復刻的是**玩法**，不使用競品的圖檔／音檔／名稱。壽司用色塊＋emoji 占位。
- 來源標籤：`[官方]` = 官網 enh-gapporisushi.com 圖文；`[攻略]` = cocoaore.jp／medalgame.net 玩家實測；`[提案]` = 開案報告內容（部分未能公開驗證）；`[換算]` = 由「極」公開配當等比推算；`[自設]` = 查不到，我設計的近似值。
- **只有 `[自設]` 與「未知清單」需要你逐條過目**，其餘照原機。

## 1. 盤面規格

| 項目 | 值 | 來源 |
|---|---|---|
| 輪盤格數 | 16 格＝15 格壽司 ＋ 1 格「老闆SP」（おやじスペシャル） | [官方][提案] |
| 抽球數 | 5 顆，逆時針依序落格 | [官方][攻略] |
| 每局壽司種類 | 5~7 種填滿 15 格（同種佔多格，格數越少越稀有） | [提案] |
| 壽司總數 | 原機 45 種；demo 用 **12 種**代表 | [提案]／[自設] |
| 抽球模型 | 5 顆球落入**互不相同**的 5 格 | [自設]（實機可能同格重複，簡化） |

**關鍵理解**：押注的單位是「**壽司種類**」不是「格子」。某種壽司佔 3 格 → 5 顆球有任一顆落在那 3 格就算命中該種。這是原機賠率只有 2~165 倍（而非數千倍）的原因，也是「格數越少賠率越高」的來源。

## 2. 押注（盤型）

| 盤型 | 押注額 | 條件 | 賠率範圍 | 來源 |
|---|---|---|---|---|
| 圓盤（丸皿） | 3 | 選 1~2 種，全命中 | 約 1.2~7 倍 | [換算] |
| 三貫（ゲタ盛） | 5 | 選 3 種，全命中 | 約 1.2~16.6 倍 | [換算] |
| 五貫（舟盛） | 10 | 選 5 種，全命中 | 約 2~165 倍 | [換算] |
| 特殊壽司（旬ネタ） | 60／120／240 | 老闆SP 中旬ネタ格 | 約 6~100 倍 | [換算] |

- 圓盤與旬ネタ**只能押盤面上出現的**；三貫與五貫**可自由組合** [官方]
- 同組合最多 **30 盤**；單一盤累積當選額達上限（demo 設 **2,500 枚**）即不能再加押 [攻略]
- 旬ネタ **每人限 1 皿** [攻略]

### 賠付公式（`[自設]`，請重點過目）

原機是「組合式浮動賠率」，公開資料查不到對應表。demo 用**機率反推**：

```
命中機率 P = P(所選每一種壽司都至少被 1 顆球命中)   ← 用容斥原理依各種壽司的格數計算
賠付倍率 = clamp( RTP / P , 該盤型的下限, 該盤型的上限 )
```

- `RTP` 預設 **0.92**，做成調參面板滑桿。
- 上下限用上表的 [換算] 範圍夾住，確保不會出現原機不存在的極端值。
- 效果驗算（6 種、格數 4/3/3/2/2/1 時）：4 格的常見壽司單押 ≈ 1.1→夾到 1.2 倍；1 格的稀有壽司單押 ≈ 2.9 倍；兩個稀有種 ≈ 7 倍；五貫押常見組合 ≈ 27 倍、押稀有組合可到上限 165 倍。**與原機公開範圍吻合**。

## 3. FREE CHOICE

- 押**三貫或五貫**時，依機率獲得 [官方]
- 前 3 球抽完後給選擇時間，可指定 1 個「未被命中的種類」視為命中 [官方]
- 取得機率：demo 預設 **35%／盤**，可調 `[自設]`（實機是內部狀態控制，攻略稱「開放期 3 種全給、回收期幾乎不給」）

## 4. 老闆SP（BG）

- 盤面固定有 1 格老闆SP；球落入 → **5 球結算完後追加第 6 顆 EX 球**，在「還沒有球的格子」上重新配置特別輪盤 [官方][攻略]
- 特別輪盤格位 [官方][攻略]：
  | 格位 | 說明 | demo 處理 |
  |---|---|---|
  | 漁 | 進入撈魚模式 | 常設 |
  | **旬漁** | **あっぱれ 才有**：中了之後「下一次的漁」會出現旬魚 | 常設（本版重點） |
  | 大漁 | 漁的上位，魚群密度高 | 機率出現（預設 15%，可調）`[自設]` |
  | 布丁（プリン） | 原機需印章 5 個 | **本版不做印章 → 改固定獎 100 枚**，UI 標註 |
  | 旬ネタ | 已買旬皿時中獎 | 機率出現 |
  | JP | 原機需印章 10 個 | **本版不做印章 → 改固定獎 1,500 枚**，UI 標註 |
  | 一發搞笑（一発ギャグ） | 空獎 | 有 |
  | 灰格 | 已有球的格子，不參與 | 有 |
- **超級老闆SP（超おやじ）不做**——那是「極」（大型版）限定，あっぱれ 沒有 [官方]

## 5. 漁チャレンジ（撈魚小遊戲）

- 限時撈魚，撈到自己盤上還沒完成的種類 → **補齊即 BINGO**；撈到沒押的種類 → 仍得該種對應贏分 [官方][攻略]
- 武器兩種：網（大範圍）／單抓（單體）
- **旬漁**：中旬漁格 → 下一次的漁出現旬魚 → 撈到旬魚 → **之後才能押該旬ネタ皿** [官方]
- 大漁：魚群（會發光、成群）密度提升，攻略說重點是用網一次撈魚群而不是撿單隻 [攻略]

| 參數 | demo 值 | 來源 |
|---|---|---|
| 時間 | 30 秒（可調） | [提案] 寫 45 秒但無公開佐證 → `[自設]` |
| 網 | 10 枚／次 | 極為 20 枚；小型版未知 → `[自設]` |
| 單抓 | 2 枚／次 | 極為 3 枚；小型版未知 → `[自設]` |
| 一般魚值 | 8~30 枚 | `[自設]` |
| 魚群單隻 | 23~50 枚 | [攻略]（極的數字，沿用） |

## 8. 技術架構

- 單檔 `index.html`（參照 `D:\demo\海克力斯`）
- `python -m http.server 8742`，`.claude/launch.json` 一鍵起服務
- **調參面板**（分頁）：節奏（落球間隔／回彈／結算停頓）｜機率（RTP／FREE 機率／大漁率／種類分布）｜賠率（上下限夾值）｜佈局
- 參數存 localStorage，可匯出 JSON
- 實作順序：輪盤與抽球 → 押注與結算 → FREE CHOICE → 老闆SP → 漁／旬漁／大漁，每塊 commit 一次
